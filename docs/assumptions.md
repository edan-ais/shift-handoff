# Planning assumptions (decided, not asked)
- First user: shift lead at a small shop.
- Scope: tasks and incidents only. Small first scope.
- Export is allowed with unresolved owner/date gaps; gaps are flagged clearly in the output.
- POC loop, fully local in the browser: paste shift notes -> review proposed tasks -> assign owners/dates -> export next-shift handoff.
- No backend, no accounts, no network calls. Data stays in the page (localStorage only).
